# Slack Message - Subscription Feature Updates

Hey team! 👋

Just pushed some updates to the Subscription feature in the Internal Admin:

**✨ New Features:**
• **One-time Charges Section** - Added a read-only section displaying one-time charges like Implementation Fee, Platform Setup Fee, and Training & Onboarding. These are synced from Chargebee and shown for reference.

• **Discount Support** - You can now apply discounts to:
  - Add-ons (fixed $ or percentage %)
  - One-time charges (fixed $ or percentage %)
  - Licenses (already existed, now consistent across all items)

• **Quarterly Billing Cycle** - Added Quarterly option alongside Monthly and Annually in the billing cycle selector.

**🗑️ Removed:**
• Trial End Date field (out of scope for subscriptions)
• Invoices tab (Finance team accesses invoices directly from Chargebee)

**🎨 UI Improvements:**
• Removed tab navigation header since we only have Overview now
• Discounts are visually displayed with original prices crossed out and discounted prices highlighted in green
• Better organization of subscription details with collapsible sections

All changes are live and ready for testing! Let me know if you have any questions or feedback. 🚀
